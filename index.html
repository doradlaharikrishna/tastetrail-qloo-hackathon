How the ranking protects the group. A restaurant must appear in every diner’s separate Qloo results. We rank that shared set with the harmonic mean of each person’s Qloo affinity, which lowers the score when even one person’s fit is weak. These are model affinity scores, not probabilities. Dining tags can influence affinity, but Qloo does not confirm a restaurant’s current menu, portion sizes, or ambience; check those details before choosing.
